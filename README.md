## ⌨️ Complete Controls Guide

### 💻 PC Keyboard Controls (Player 1)
| Key | Action | Description |
| :--- | :--- | :--- |
| <kbd>W</kbd> | **Jump** | Aerial jump stance |
| <kbd>S</kbd> | **Crouch** | Low defense stance |
| <kbd>A</kbd> / <kbd>D</kbd> | **Move Left / Right** | Walk footwork |
| <kbd>Q</kbd> or <kbd>Shift</kbd> | **Guard Shield** | Deploy hexagonal energy block barrier |
| <kbd>F</kbd> | **Light Punch (LP)** | Fast straight jab |
| <kbd>G</kbd> | **Heavy Punch (HP)** | Power dragon punch haymaker |
| <kbd>H</kbd> | **Light Kick (LK)** | Quick front snap kick |
| <kbd>Y</kbd> | **Heavy Kick (HK)** | High roundhouse kick |
| <kbd>S</kbd> + <kbd>D</kbd> + <kbd>F</kbd> | 💥 **Special 1** | Ki Hadouken fireball blast |
| <kbd>S</kbd> + <kbd>W</kbd> + <kbd>G</kbd> | ⚡ **Special 2** | Rising Dragon Uppercut leap |

### 📱 Virtual Analog Joystick & Arcade Buttons
- **Left Thumb 360° Joystick**: Drag smoothly in any direction for walking, jumping, crouching, or crouch-guard.
- **Right Thumb Arcade Buttons**:
  - 🥊 **LP**: Light Punch Jab
  - 💥 **HP**: Heavy Dragon Strike
  - 🦵 **LK**: Light Kick
  - 🌪️ **HK**: Heavy Roundhouse Kick
  - ⚡ **SP 1**: Ki Hadouken Blast
  - 🌋 **SP 2**: Rising Dragon Uppercut
  - 🛡️ **GUARD**: Energy Block Shield
