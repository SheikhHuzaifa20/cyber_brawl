# 🥊 CYBER BRAWL 3D: WORLD CHAMPIONSHIP (ULTRA VIP EDITION)

A high-performance **3D Arcade Fighting App** built with **Three.js WebGL**, featuring an expanded roster of **3D Male Bodybuilders & Female Ninjas/Martial Artists** (inspired by SNK & Capcom arcade grid reference art), **Web Audio Speech & Formant Voice Synthesizer**, **Cinematic 3D VS Match Screen**, **SF6 Neon HUD**, and **Dual Controls (PC Keyboard + Mobile Touch Joystick & Buttons)**.

---

## ⌨️ Complete Key Controls & Bindings Guide

### 💻 PC Keyboard Bindings (Player 1)
| Key Binding | Game Action | Voice / SFX Effect |
| :--- | :--- | :--- |
| <kbd>W</kbd> | **Jump Up** | Ground Jump Dust |
| <kbd>S</kbd> | **Crouch Down** | Lower Stance |
| <kbd>A</kbd> | **Move Left / Guard Block** | Hold away from opponent to Guard |
| <kbd>D</kbd> | **Move Right / Guard Block** | Hold away from opponent to Guard |
| <kbd>F</kbd> | **Light Punch** | Light Fist Thrust + "HAH!" Voice Cry |
| <kbd>G</kbd> | **Heavy Punch** | Heavy Power Strike + "TAKE THIS!" Voice Cry |
| <kbd>H</kbd> | **High Kick** | High Leg Kick + "HYAH!" Voice Cry |
| <kbd>S</kbd> + <kbd>D</kbd> + <kbd>F</kbd> | 💥 **Special Attack 1** | Launch 3D Energy Orb / Kunai Blast + Voice Callout |
| <kbd>S</kbd> + <kbd>W</kbd> + <kbd>G</kbd> | ⚡ **Special Attack 2** | Flying Dragon Uppercut / Lariat + Voice Callout |

### 📱 Mobile Screen Touch Controls
- **Left Virtual D-Pad**: Touch **▲ JUMP**, **▼ CROUCH**, **◄ LEFT**, **RIGHT ►**
- **Right Action Buttons**:
  - 🥊 **PUNCH**: Light Punch + Voice Shout
  - 💥 **H.PUNCH**: Heavy Punch + Voice Shout
  - 🦵 **KICK**: High Kick + Voice Shout
  - 💥 **SPECIAL 1**: Launch 3D Fireball / Kunai + Voice
  - ⚡ **SPECIAL 2**: Flying Dragon Uppercut + Voice
  - 🛡️ **GUARD**: Guard Stance

## 🚀 How to Launch & Play

### PC / Desktop Launch
1. Open folder: `C:\laragon\www\volt`
2. Double-click **`index.html`** to launch in Google Chrome, Microsoft Edge, Safari, or Brave.
3. Click **1 PLAYER VS 3D CPU** to enter the 3D Battle Arena!

### Mobile / Tablet Launch
1. Visit `http://volt.test` (or `http://localhost/volt`) on your smartphone.
2. Touch on-screen Virtual Arcade Joystick D-Pad and Action Buttons to play!
